# quanttide-media

量潮新媒体运营

## 概述

量潮新媒体运营（quanttide-media）是量潮知识管理体系中的**新媒体运营**领域，以运营实践方式承载社交媒体矩阵的运营与管理。

## 领域边界

- **内容运营**：内容策划、生产、分发与效果追踪
- **矩阵运营**：多平台账号体系、内容同步与差异化运营
- **用户运营**：粉丝增长、互动维护、私域引流
- **数据运营**：运营数据采集、分析与策略迭代

> 与 customer 领域的分工：本领域承载「公开社交渠道运营」，customer 承载「客户关系与销售过程」。
> 与 connect 领域的分工：本领域承载「对外传播内容」，connect 承载「组织内外部沟通流程」。
